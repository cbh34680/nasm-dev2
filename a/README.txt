
exit           : 終了コードを受け入れ、現在のプロセスを終了します。

string_length  : 文字列へのポインタを受け入れ、その長さを返します。

print_string   : ヌル終端文字列へのポインタを受け入れ、それを stdout に出力します。

print_char     : 文字コードを最初の引数として直接受け入れ、それを stdout に出力します。

print_newline  : コード 0xA の文字を出力します。

print_uint     : 符号なし 8 バイト整数を 10 進数形式で出力します。

print_int      : 符号付き 8 バイト整数を 10 進数形式で出力します。

read_char      : stdin から 1 文字を読み取り、それを返します。入力ストリームの終わりが
                 発生した場合、0 を返します。

read_word      : 引数としてバッファアドレスとサイズを受け入れます。stdin から次の単語を
                 読み取ります（空白をスキップしてバッファに入れます）。単語が指定された
                 バッファに対して大きすぎる場合は停止して 0 を返します。それ以外の場合は
                 バッファアドレスを返します。この関数は受け入れられた文字列をヌル終端する
                 必要があります。

parse_uint     : ヌル終端文字列を受け入れ、その先頭から符号なし数を解析しようとします。
                 解析された数を rax に、その文字数を rdx に返します。

parse_int      : ヌル終端文字列を受け入れ、その先頭から符号付き数を解析しようとします。
                 解析された数を rax に、その文字数を rdx に返します（符号がある場合は
                 それを含む）。符号と数字の間にスペースは許可されません。

string_equals  : 2 つの文字列へのポインタを受け入れ、それらを比較します。等しい場合は 1 を、
                 そうでない場合は 0 を返します。

string_copy    : 文字列へのポインタ、バッファへのポインタ、およびバッファの長さを受け入れ
                 ます。文字列を宛先にコピーします。文字列がバッファに収まる場合は宛先
                 アドレスが返されます。そうでない場合は 0 が返されます。
