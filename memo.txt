

Linux 64bit (System V ABI) の関数ルール

    引数の渡し方
        関数に渡す引数は順に以下のレジスタへ格納します。
            第1引数: RDI
            第2引数: RSI
            第3引数: RDX
            第4引数: RCX
            第5引数: R8
            第6引数: R9

    戻り値の返し方
        関数の実行結果（戻り値）は RAX（または EAX / AL）に入れます。

    レジスタの保存ルール（スクラッチ vs 温存）
        関数内で自由に使って破棄してよいレジスタ（Callee-trashed）:
            RAX, RCX, RDX, RSI, RDI, R8, R9, R10, R11

        関数内で変更する場合、呼び出し前の値を退避・復元すべきレジスタ（Callee-saved）:
            RBX, RBP, R12, R13, R14, R15

        （※これらを使う場合は関数冒頭で push rbx し、ret の前に pop rbx します）



Linux 64bit (x86_64 Syscall ABI) のシステムコールルール

    引数の渡し方
        システムコールに渡す引数は順に以下のレジスタへ格納します。
            システムコール番号: RAX
            第1引数: RDI
            第2引数: RSI
            第3引数: RDX
            第4引数: R10  (※通常の関数呼び出しの RCX とは異なる)
            第5引数: R8
            第6引数: R9

    戻り値の返し方
        実行結果（戻り値）は RAX に入ります。
        ※ 成功時は 0 または正の値、エラー時は -1 〜 -4095 の負の値（-errno）が返ります。

    レジスタの保存ルール（破壊 vs 保持）
        syscall 命令の実行によって破壊されるレジスタ:
            RAX, RCX, R11
            ※ RCX には復帰用 RIP、R11 には RFLAGS が CPU によって自動退避・上書きされます。

        syscall 実行後も値が保持されるレジスタ:
            RBX, RBP, R12, R13, R14, R15, RDI, RSI, RDX, R10, R8, R9, RSP
            ※ 引数用レジスタ（RDI 〜 R9）を含め、RAX / RCX / R11 以外の汎用レジスタはカーネルによって保持されます。



x86-64 汎用レジスタおよび特殊レジスタの用途一覧 (Linux / System V AMD64 ABI)
    rax      関数の戻り値、システムコール番号               Accumulator（アキュムレータ）
    rdi      第1引数                                        Destination Index（文字列操作の転送先）
    rsi      第2引数                                        Source Index（文字列操作の転送元）
    rdx      第3引数、乗除算の補助（高位ビット格納）        Data（データ）
    rcx      第4引数、ループカウンタ、シフト回数            Counter（カウンタ）
    r8       第5引数                                        拡張レジスタ (r8d / r8w / r8b)
    r9       第6引数                                        拡張レジスタ (r9d / r9w / r9b)
    r10      スクラッチ（作業用）、システムコール第4引数    Caller-saved
    r11      スクラッチ（作業用）、syscall時にrflags退避    Caller-saved
    rbx      呼出元退避                                     Callee-saved（前後で値を保持・復元が必要）
    r12~r15  呼出元退避                                     Callee-saved（前後で値を保持・復元が必要）
    rsp      スタックポインタ                               現在のスタックトップのアドレスを指す
    rbp      ベース（フレーム）ポインタ                     スタックフレームの基準アドレスを指す
    rip      インストラクションポインタ                     次に実行する命令のアドレス
    rflags   条件フラグ                                     ZF, CF, SF, OF などを保持


x86-64 レジスタ対応表

    --------------------------------------------------------------------------------
    1. 伝統的な汎用レジスタ (8種)
    --------------------------------------------------------------------------------
    64bit   32bit   16bit   8bit(上位) 8bit(下位) 主要な用途 / System V ABI役割
    --------------------------------------------------------------------------------
    rax     eax     ax      ah         al         アキュムレータ / システムコール番号 / 戻り値
    rbx     ebx     bx      bh         bl         ベースレジスタ (Callee-saved)
    rcx     ecx     cx      ch         cl         カウンタ / 関数第4引数
    rdx     edx     dx      dh         dl         データ / 関数第3引数 / システムコール第3引数
    rsi     esi     si      (なし)     sil        ソース / 関数第2引数 / システムコール第2引数
    rdi     edi     di      (なし)     dil        デスティネーション / 関数第1引数 / システムコール第1引数
    rbp     ebp     bp      (なし)     bpl        ベースポインタ (Callee-saved)
    rsp     esp     sp      (なし)     spl        スタックポインタ
    --------------------------------------------------------------------------------


    --------------------------------------------------------------------------------
    2. 拡張汎用レジスタ (8種)
    --------------------------------------------------------------------------------
    64bit   32bit   16bit   8bit(下位)            主要な用途 / System V ABI役割
    --------------------------------------------------------------------------------
    r8      r8d     r8w     r8b                   関数第5引数 / システムコール第5引数
    r9      r9d     r9w     r9b                   関数第6引数 / システムコール第6引数
    r10     r10d    r10w    r10b                  システムコール第4引数 (※関数呼び出し時は rcx)
    r11     r11d    r11w    r11b                  一時レジスタ (syscall実行時にRFLAGS退避用)
    r12     r12d    r12w    r12b                  汎用 (Callee-saved)
    r13     r13d    r13w    r13b                  汎用 (Callee-saved)
    r14     r14d    r14w    r14b                  汎用 (Callee-saved)
    r15     r15d    r15w    r15b                  汎用 (Callee-saved)
    --------------------------------------------------------------------------------
    ※ 拡張レジスタの接尾辞: d = dword (32bit), w = word (16bit), b = byte (8bit)


    --------------------------------------------------------------------------------
    3. レジスタ構造イメージ (raxの例)
    --------------------------------------------------------------------------------
    +---------------------------------------------------------------+
    |                             rax                               | (64 bit)
    +-------------------------------+-------------------------------+
                                    |              eax              | (32 bit) ※書き込み時上位0クリア
                                    +---------------+---------------+
                                                    |      ax       | (16 bit) ※上位保持
                                                    +-------+-------+
                                                    |  ah   |  al   | (8 bit×2) ※上位保持
                                                    +-------+-------+
